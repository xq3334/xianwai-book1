# 《线外 · 第一部：被讨厌的勇气》

一款受阿德勒心理学启发的原创叙事选择游戏。

## ✨ 已完成功能

### 核心内容
- ✅ 序章 + 七个章节 + 终章（完整剧情）
- ✅ 12张知识卡片（目的论、课题分离、被讨厌的勇气等）
- ✅ 六种结局，根据隐藏特质判定
- ✅ 暂停观察、课题分离拖拽、现实练习

### 视觉与交互
- ✅ **Python生成的手绘风格SVG插画**
  - 6个场景背景（教室、走廊、缠绕、清晰、默认）
  - 6个人物线稿（主角、林澈、顾言、许禾、沈老师、妈妈）
  - 标题插画（人物剪影 + 辐射线）
- ✅ **缓慢的落笔动画**
  - 每条线按层次错开起笔时间
  - 36秒一个周期的极慢呼吸式漂移
- ✅ 人物根据说话人自动出现在舞台
- ✅ 纸张纹理、线条抖动、排线质感

### 系统功能
- ✅ 存档/读档、章节选择
- ✅ 烦恼笔记（现实练习记录）
- ✅ 线外手册（解锁的知识卡片）
- ✅ 键盘导航（空格/回车推进对话）
- ✅ 响应式设计

## 🎨 美术资源生成

所有插画由Python脚本生成，位于 `artgen/` 目录：

```bash
cd artgen
py -3 build_all.py
```

生成的SVG文件会保存到：
- `xianwai-book1/assets/scenes/` - 场景背景
- `xianwai-book1/assets/characters/` - 人物线稿

**核心绘图工具：**
- `sketch.py` - 手绘线条基础库（抖动、排线、SVG输出）
- `figures.py` - 人物构建模块
- `build_all.py` - 统一生成脚本

**美术风格：**
- 参考文学插画绘本（《简爱》游戏气质）
- 钢笔线稿 + 纸张肌理 + 低饱和色 + 大量留白
- 所有线条带轻微抖动，避免「电脑画的」感觉
- 人物靠发型、姿态、肩线区分，不画五官细节

## 🚀 本地运行

静态站点，无需构建：

```bash
# 已内置Node服务器
node xianwai-dev-server.mjs
# 访问 http://localhost:5173/

# 或用Python
cd xianwai-book1
python -m http.server 8000
```

## 📦 部署到 GitHub Pages

1. 把 `xianwai-book1/` 文件夹推到仓库
2. 仓库设置 → Pages → 选择分支根目录
3. 访问 `https://你的用户名.github.io/仓库名/`

`.nojekyll` 文件已包含，告诉GitHub不要用Jekyll处理。

## 🎮 游戏特色

**不是知识问答，而是让玩家「经历」：**
- 每个选择都有真实代价
- 结局呈现的是生活方式，不是分数
- 知识卡片在玩家需要时解锁
- 现实练习鼓励玩家在生活中尝试

**视觉呈现：**
- 一笔一笔画出来的缓慢动画
- 人物随对话自动进场
- 背景极慢地呼吸（36秒周期）
- 线条抖动、排线质感、纸张颗粒

## 📂 项目结构

```
xianwai-book1/
├── index.html
├── .nojekyll
├── styles/
│   ├── paper.css      # 纸张纹理、字体、基础
│   ├── scene.css      # 标题和剧情界面、动画
│   └── panels.css     # 覆盖层面板
├── src/
│   ├── main.js
│   ├── engine.js      # 场景系统、分支跳转
│   ├── state.js       # 存档管理
│   ├── art/
│   │   └── stage.js   # SVG加载、落笔动画
│   ├── ui/            # 对话、选择、观察、练习等
│   └── content/       # 9章剧情 + 知识卡片 + 6种结局
└── assets/
    ├── scenes/        # 6个场景SVG（Python生成）
    └── characters/    # 6个人物SVG（Python生成）

artgen/                # 美术资源生成工具
├── sketch.py
├── figures.py
└── build_all.py
```

## 🛠 技术栈

- 纯 HTML / CSS / JavaScript (ES modules)
- 无框架、无构建工具、无npm依赖
- Python 3.10 + Pillow（仅用于生成SVG）
- localStorage存档
- 原生拖拽API + 触屏点击兼容

## ⚠️ 关于内容

- 本作为原创故事，受《被讨厌的勇气》启发，不是官方改编
- 「被讨厌」≠ 被欺凌/威胁/伤害，游戏强调寻求帮助
- 目的论不是用来责备当事人
- 过去经历、家庭、现实处境都会真实影响一个人
